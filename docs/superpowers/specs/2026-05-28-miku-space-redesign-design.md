# Miku Space 全站重设计 — 设计文档

## 概述

将个人博客/作品展示站点从通用简洁风格升级为 **初音未来主题二次元梦幻风格**，以低饱和梦幻色调、半透明毛玻璃卡片、圆润圆角、粒子花瓣特效为核心视觉语言，打造朦胧治愈的个人空间。

## 设计原则

1. **梦幻低饱和** — 色彩柔和不刺眼，以淡粉/淡蓝/淡青为基底
2. **毛玻璃通透** — 卡片使用 backdrop-blur 营造朦胧空气感
3. **圆润友好** — 大圆角无处不在，消除锐利感
4. **板块拼接** — 首页像拼图一样由多个独立毛玻璃卡片组成
5. **初音点缀** — 青绿色 #A8E6E1 作为灵魂色，降低饱和度后融入整体

## 字体系统

### 字体族

- **英文/数字**：`Outfit`（Google Fonts）— 几何感、笔画饱满、现代清晰
- **中文**：系统字体栈 `"PingFang SC", "Microsoft YaHei", sans-serif`
- **时钟/数字**：`monospace` 或 Outfit 的等宽数字

### 字体规格

| 层级 | 大小 | 字重 | 字间距 | 用途 |
|------|------|------|--------|------|
| H1 | 28px | 700 | -0.02em | 页面大标题、用户名 |
| H2 | 20px | 700 | -0.01em | 区块标题 |
| H3 | 16px | 600 | 0 | 卡片标题 |
| Body | 14px | 400 | 0 | 正文描述 |
| Caption | 12px | 400 | 0 | 辅助信息、时间 |
| Small | 10-11px | 500 | 0.02em | 标签、统计单位 |


## 图标风格

使用 **lucide-react** 图标，通过以下四种方式风格化：

1. **渐变背景 + 深色描边** — 主功能图标（如 Logo）
2. **半透明底 + 主题色描边** — 导航/工具图标
3. **毛玻璃底 + 灰色描边** — 次要操作图标
4. **白色圆底 + 纯色填充** — 徽章/状态图标

所有图标统一使用 2px 描边，圆角 stroke-linecap/linejoin。

## 首页设计

### 背景特效（仅首页）

#### 飘落花瓣系统
- Canvas 2D 粒子渲染
- 花瓣形状：简化 SVG path 或椭圆
- 双色花瓣：淡粉 `#F5C6D0`（60%）+ 淡青 `#A8E6E1`（40%）
- 数量：桌面 30-50 片，移动端 15-20 片
- 运动：匀速下落 + 正弦波左右摇摆 + 轻微旋转
- 透明度：0.3-0.7，随机变化
- 随滚动密度降低

#### 浮动光斑粒子
- 柔和圆形 blur 光点
- 颜色：淡白/淡青，大小 2-8px，blur 4-12px
- 数量：15-25 个
- 运动：极慢速随机漂浮 + 呼吸透明度变化

#### 性能策略
- `requestAnimationFrame` + delta time 计算
- `document.hidden` 时暂停动画
- `will-change: transform` 硬件加速
- `prefers-reduced-motion` 自动禁用

### 页面结构

#### 1. 导航栏
全局毛玻璃导航，见上文。

#### 2. Hero 区域（左右分栏）

**左栏：个人卡片**
- 头像（64px，圆角 16px，渐变背景）
- 用户名（H1）+ 简介
- 统计数字行：文章数 / 笔记数 / 作品数（彩色数字）
- 社交图标行：GitHub / Twitter / Email / Discord

**右栏：音乐播放器**
- 专辑封面（52px，圆角 14px）+ 歌名/歌手
- 进度条（渐变填充）+ 时间显示
- 播放控制：上一首 / 播放/暂停 / 下一首
- 播放按钮使用渐变圆形

#### 3. 歌词条
- 单行居中显示
- 当前歌词白色，待播放歌词灰色
- 打字机光标效果（`|` 闪烁）
- 毛玻璃背景条

#### 4. 下方左右分栏（板块拼接）

**左栏（约 40%）：**

- **兴趣轮播卡片**
  - 单卡片滑动展示
  - 每张卡片：图标 + 兴趣名称 + 简介
  - 渐变色背景（根据兴趣类型变化）
  - 底部指示器点（当前主题色，其他灰色）
  - 支持自动轮播（5秒）和手动切换

- **个性化时钟**
  - 大字号数字时间（32px，monospace）
  - 日期 + 星期
  - 时段图标（🌙/☀）+ 温度（预留天气 API）

- **竖屏绘画作品**
  - 竖向图片展示区域（约 140px 高）
  - 可轮播展示多张喜欢的插画/画作
  - 顶部标题 + 刷新/切换按钮

**右栏（约 60%）：**

- **精选作品（纵向列表）**
  - 3-4 条横向卡片
  - 每条：左侧缩略图（60px）+ 右侧标题/描述
  - 顶部标题栏 + "查看全部"链接

- **最新内容（2×2 网格）**
  - 4 张小卡片呈 2×2 布局
  - 每张：类型标签（彩色）+ 标题 + 日期
  - 顶部标题栏 + "更多"链接

## 其他页面设计

### 列表页（作品 / 文章 / 笔记）

- 顶部：毛玻璃搜索/筛选栏
- 主体：响应式网格卡片（移动端 1 列，平板 2 列，桌面 3 列）
- 卡片：封面图 + 标题 + 描述 + 标签 + 日期
- 统一毛玻璃风格，hover 上浮 + 阴影加深
- 无动态特效

### 详情页

- 可选封面图（全宽，圆角 lg）
- 毛玻璃标题区：标题 + 元信息 + 标签
- Markdown 正文：
  - 更大行高（1.8）
  - 引用块：左侧主题色边框 + 淡色背景
  - 代码块：毛玻璃背景 + 圆角 + 语法高亮
  - 链接：主题色 + hover 下划线
- 底部：上一篇/下一篇导航

### 关于页

- 顶部：大号头像 + 名字 + 简介（居中）
- 时间线区块：经历/里程碑（毛玻璃卡片）
- 联系信息：图标 + 链接

### 搜索页

- 居中大型搜索输入框（毛玻璃风格）
- 聚焦时柔和光晕效果
- 结果按类型分组（文章/笔记/作品）
- 高亮匹配关键词

## 动画规范

### 入场动画
- 使用 Framer Motion
- 初始状态：`opacity: 0, y: 20`
- 动画：`opacity: 1, y: 0`
- 时长：`0.5s`，缓动：`ease-out`
-  stagger：每个卡片间隔 `0.1s`

### Hover 动画
- 过渡：`0.3s ease`
- 变换：`translateY(-2px)`
- 阴影加深

### 页面切换
- 内容淡入淡出
- 时长：`0.3s`

## 技术实现要点

1. **Canvas 粒子**：使用 `useRef` + `useEffect` 封装为独立组件，首页挂载时初始化
2. **音乐播放器**：HTML5 Audio API，支持播放/暂停/进度控制，自动播放需处理浏览器策略
3. **轮播图**：使用 `framer-motion` AnimatePresence 实现滑动动画
4. **时钟**：`setInterval` 每秒更新，使用 `useState` + `useEffect`
5. **主题切换**：保留现有 next-themes，深色为默认主题
6. **字体加载**：`next/font/google` 加载 Outfit，配置 `display: swap`
